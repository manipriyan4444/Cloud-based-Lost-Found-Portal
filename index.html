Process

Three entries, one file.

Every case moves through the same sequence, whether it was filed from an airport counter or a phone in someone's pocket.

CASE 01

File the report

Describe the item, when and where it went missing or turned up. A photo helps the match run better, but it isn't required.

CASE 02

The ledger runs the match

Every new entry is checked against lost and found reports the moment it's filed — across every branch connected to the system, not just the one it came from.

CASE 03

Claim it

Get notified the moment there's a match. Verify a few details, then pick the item up in person or arrange a courier.

Infrastructure

One ledger. Every branch.

Lost & Found Co. doesn't run separate books per location. Every branch writes to the same case file in real time, so an item found across town from where it was lost still gets matched.
